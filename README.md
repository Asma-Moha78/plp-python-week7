# Week 7 Assignment: My Notes & The Report Builder

## Project Files

- my_notes.py - Writes, appends, reads and counts notes in a text file.
- my_notes.txt - Stores the four notes created by my_notes.py.
- report_builder.py - Reads learner data from a CSV file and generates a report.
- hubs.csv - Contains learner names, hub names and scores.
- report.txt - Contains the generated learner performance report.
- README.md - Describes the project files and assignment.

## What happens if "a" is changed to "w" in Question 1?

Changing append mode ("a") to write mode ("w") erases the first three notes before writing the fourth note. Only the fourth note will remain in the file.
